# Repository Guidelines

All repository guidelines and instructions have been consolidated into [CLAUDE.md](./CLAUDE.md). Please read that file for project structure, build commands, coding style, and testing guidelines.

## Cursor Cloud specific instructions

### Service Overview

This is a **pure frontend** React Native web application. There is no local backend — the app proxies API requests to Expensify's production servers via a local proxy on port 9000.

| Service | Port | Description |
|---------|------|-------------|
| Webpack Dev Server | 8082 (HTTPS) | Main web app at `https://dev.new.expensify.com:8082/` |
| Web Proxy | 9000 (HTTP) | CORS proxy forwarding to `www.expensify.com` |

Both are started together by `npm run web` (uses `concurrently`).

### Running the Dev Server

```bash
npm run web
```

Initial webpack compilation takes **2–4 minutes**. Wait for it to finish before testing in a browser.

### Prerequisites (already handled by snapshot / update script)

- **Node.js 20.19.5** via nvm (see `.nvmrc`)
- `npm install` for dependencies
- HTTPS certs at `config/webpack/certificate.pem` and `config/webpack/key.pem` (generated by `mkcert` via `npm run setup-https`)
- `/etc/hosts` entry: `127.0.0.1 dev.new.expensify.com`
- `mkcert` and `libnss3-tools` system packages

### Common Commands

See `CLAUDE.md` → **Command Reference** for the full list. Key commands:

- **Lint**: `npm run lint` (max 425 warnings allowed)
- **Typecheck**: `npm run typecheck`
- **Tests**: `npm run test` (Jest)
- **Format**: `npm run prettier`
- **Web dev**: `npm run web`

### Dev Environment Sign-In

- Enter any email with a `+` suffix (e.g. `testuser+agent1@gmail.com`)
- New accounts: click **Join**; existing accounts: magic code is always `000000`
- The dev environment may auto-authenticate without requiring the magic code

### Gotchas

- Webpack compilation is memory-intensive; `typecheck` sets `--max_old_space_size=8192`.
- The `npm run web` command auto-opens a browser tab; in headless environments, ignore the open failure and use `curl` or Playwright to verify the server.
- The postinstall script (`scripts/postInstall.sh`) applies patches via `patch-package`. If patches fail after dependency changes, run `npm run clean` then `npm install` again.
- ESLint is slow on first run (~30s per file) due to Babel config parsing. Subsequent runs are faster.
- Do **not** create a `.env` file unless explicitly needed; the app uses built-in defaults for development.
